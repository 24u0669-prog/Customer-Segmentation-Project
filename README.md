# 🎯 Customer Segmentation & Business Intelligence Dashboard

## 📌 Project Overview

**Customer Segmentation & Business Intelligence Dashboard** is an interactive web-based analytics project designed to present customer, transaction, revenue, and business insights in a simple and professional dashboard.

The project provides multiple connected pages that allow users to navigate between a **Power BI-style live dashboard**, **Detailed Analytics**, and **Business Insights** using interactive buttons.

---

## 🚀 Features

### 📊 Power BI Live Dashboard

* Customer count visualization by age
* Customer distribution charts
* Total customer count
* Total amount/revenue overview
* Power BI-style dashboard interface
* Responsive layout

### 📈 Detailed Analytics

* Total revenue
* Total customers
* Total transactions
* Average order value
* Customer demographics
* Education distribution
* Income distribution
* Transaction analysis
* Product/category analysis
* Age distribution

### 💡 Business Insights

* Strategic recommendations
* Customer retention strategies
* Revenue growth opportunities
* Target customer identification
* Upselling and cross-selling recommendations
* Tier-2 city expansion opportunities
* Marketing recommendations

## 🖥️ Website Navigation

The website is designed as a connected multi-page application:

```text
                    🏠 Home
                       │
          ┌────────────┼────────────┐
          │            │            │
          ▼            ▼            ▼
       📊 Power BI   📈 Analytics  💡 Insights
          │            │            │
          └────────────┴────────────┘
                       │
                       ▼
                 ← Back to Home
```

Users can press the buttons on the homepage to open the corresponding pages.
